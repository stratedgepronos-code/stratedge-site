 01 / PRÉPARER LE MATCH

Le point de départ de l’analyse.

Charge ton export CSV Packball, puis associe ses colonnes. Les moyennes doivent porter sur le même échantillon, en matchs complets. L’import doit précéder le coup d’envoi.

Installer le collecteur Tampermonkey · Télécharger le modèle CSV

L’identifiant Packball est obligatoire. S’il manque dans ton export, tu peux le renseigner dans l’aperçu, à partir du match affiché dans la console. Les dates sans fuseau sont interprétées dans le fuseau de ton navigateur, affiché ci-dessous.
