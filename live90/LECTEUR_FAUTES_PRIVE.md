# Lecture privée des fautes

Dans le radar, ouvrir **Lecture privée des fautes** juste au-dessus du tableau.
Installer le deuxième userscript dans Tampermonkey (le collecteur Packball reste activé), puis recharger le radar et les onglets de commentaire. Si le navigateur télécharge le fichier sans l'installer, utiliser **Tampermonkey → Tableau de bord → Utilitaires → Importer depuis un fichier**.

Choisir le match et les noms des joueurs à surveiller, tels que le commentaire les écrit, dans leur équipe respective (point-virgule pour séparer les noms). Vérifier l'identité du match et le onze sur le terrain. En mode personnel, saisir uniquement ses observations à l'instant présent. Pour un fil dont la lecture automatique est permise, associer son URL de match dans la vue Commentaires, activer la case correspondante et garder les deux onglets ouverts. La case ne confère pas de droit d'utilisation du fournisseur. Les observations manuelles restent disponibles sans source branchée. Flashscore : URL du direct texte français avec mid ; MatchEnDirect : fiche du match avec p=commentaires. Aucun accès par API privée, aucun téléchargement automatique de pages.

Le navigateur observe uniquement les nouvelles lignes visibles. Sans indicateur de connexion et sans lignes reconnues, il ne collecte rien. Un rappel verbal identifié, puis une faute explicitement commise par le même joueur et à une minute ultérieure, sont rapprochés des compteurs et de la confirmation cartons du radar de la même équipe. Aucune nouvelle règle prédictive dans le moteur. Les fenêtres temporelles sont des garde-fous de lecture, pas une estimation de probabilité. Un fil incomplet ne permet pas de garantir que toutes les sorties et tous les cartons ont été vus. Un carton, un remplacement ou une correction reconnus neutralisent la séquence, y compris si leur attribution est incertaine.

Le panneau reste local au navigateur. Une notification **supplémentaire privée** est facultative : sur l'onglet StratEdge, menu du userscript **Configurer ou désactiver Telegram privé**, ouvrir au préalable le bot en conversation privée et appuyer sur Démarrer. Entrer les identifiants uniquement sur son navigateur ; ne pas les transmettre à un interlocuteur. La destination est contrôlée par getChat ; groupes et canaux sont refusés. Le nouveau lecteur ne modifie ni le bot collectif, ni l'historique de paris, ni les données de l'analyste. Sans configuration privée, aucun message Telegram supplémentaire. Si le navigateur met un onglet en veille, le signal attend une lecture fraîche. Les notes structurées expirent, le texte original n'est pas archivé.

## Flux international (sans onglet de presse)

Créer un compte SoccersAPI avec les ligues voulues, vérifier l’offre gratuite et le quota dans le tableau de bord. Dans le menu Tampermonkey **du radar**, choisir **Configurer ou oublier la clé SoccersAPI**, puis sélectionner une rencontre et **Suivre avec SoccersAPI**. Aucun nom à saisir si les compositions sont confirmées. Le match est identifié sur les deux équipes et le coup d’envoi. Les commentaires disponibles sont demandés en anglais et les faits reconnus restitués en français, sans service de traduction ni IA payante. Les phrases non reconnues sont ignorées. Un match à la fois ; une lecture au plus toutes les 45 secondes, plafond local partagé de 90 appels par jour UTC (environ une heure de surveillance continue). Une limite fournisseur inférieure s’applique en premier. Une clé ne garantit ni couverture ni rappels verbaux. Le mode international nécessite uniquement l’onglet radar ouvert et actif. Documentation : https://docs.soccersapi.com/fixtures/match_comments/
